# Contributing

We love contributions! Here's how to help:

## Getting Started
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Install dependencies (`npm install`)
4. Make your changes
5. Build and verify (`npm run build`)
6. Commit and push
7. Open a Pull Request

## Guidelines
- Keep it simple — this is a children's app
- No tracking, analytics, or external scripts
- All content must be kid-safe and ad-free
- Match the existing code style and component patterns
- Ensure the build passes before submitting

## Pull Request Process
1. Update the README if needed
2. Update package version if applicable
3. Your PR will be reviewed within 48 hours

## Code of Conduct
Be respectful, inclusive, and constructive.
